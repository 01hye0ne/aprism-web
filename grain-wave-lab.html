Grain Wave 검토

React Bits Pro 의 Grain Wave 배경 효과를 APRISM 화면에 쓸 수 있는지 판단하기 위한 페이지입니다. 아래 무대는 공개된 문서의 17개 속성만 보고 다시 만든 것이고, 정품 컴포넌트의 소스가 아닙니다.

지금 이 저장소에는 그대로 넣을 수 없습니다

문서대로 npx shadcn@latest add @reactbits-starter/grain-wave-tw 를 돌려봤고, 세 군데서 막힙니다.

  • 라이선스 키가 없습니다. 환경변수에도, 저장소에도 없습니다. 키를 넣을 .env.local 의 변수 이름은 Pro 문서 안쪽에 있어 밖에서는 확인되지 않습니다.
  • 레지스트리 주소를 모릅니다. 이름만 물고 실행하면 Unknown registry "@reactbits-starter" 로 끊깁니다. 주소 역시 로그인해야 보이는 쪽에 있습니다.
  • 이 저장소는 정적 HTML 입니다. shadcn CLI 는 React + TypeScript 프로젝트를 전제합니다 — package.json · tsconfig.json · components.json 이 모두 있어야 하는데 aprism-web 에는 빌드 단계 자체가 없습니다.

앞의 둘은 키와 레지스트리 주소만 주시면 바로 풀립니다. 셋째는 판단이 필요합니다 — 정품을 쓰려면 이 저장소에 React 와 번들러를 들여야 하고, 그건 지금의 “파일 열면 바로 보이는” 구조를 바꾸는 일입니다.

다시 만든 결과

문서에 적힌 속성 이름 · 기본값 · 설명을 그대로 따라 WebGL 로 구현했습니다. 빌드 단계가 필요 없습니다. 정품과 픽셀 단위로 같다고는 말할 수 없습니다 — 소스를 볼 수 없어 파형을 쌓고 그레인을 뿌리는 방식은 제 해석입니다. 쓸 만한지, 아니면 정품을 들여야 할지 여기서 판단해 주세요.

재현 · WebGL2 · 정품 소스 아님

문서에 적힌 속성

pro.reactbits.dev/docs/components/grain-wave 에서 읽은 표 그대로입니다. 위 조작판의 순서·기본값이 이것과 같습니다.

정품을 들이려면

키와 레지스트리 주소를 받으면 이 순서로 진행합니다. 지금은 1·2 번에서 멈춰 있습니다.

# 1. 라이선스 키 — 변수 이름은 Pro 문서에서 확인이 필요합니다
.env.local
  REACTBITS_...=<라이선스 키>

# 2. components.json 에 레지스트리 등록 — 주소도 확인이 필요합니다
{
  "registries": {
    "@reactbits-starter": "<레지스트리 주소>"
  }
}

# 3. 설치
npx shadcn@latest add @reactbits-starter/grain-wave-tw

# 4. 이 저장소에 없는 것 — 셋 다 새로 들여야 합니다
package.json · tsconfig.json · React 런타임과 번들러
