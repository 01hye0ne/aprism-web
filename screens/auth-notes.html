스플래시 · 로그인

Figma UI_01/ CM-01 스플래시(630:3480) · UI_01/ CM-02 로그인 화면(630:3481) 를 옮긴 것입니다. 디자인 확정 전이라고 하셔서 구조만 그대로 두고 어긋난 값은 고쳤습니다. 아래가 고친 자리 전부입니다.

1. 로그인 패널 폭 — 791 이 아니라 800 입니다

Figma 는 Brand Panel 1120 + Login Panel 791 = 1911 이라 오른쪽 끝에 9 가 빕니다. 어느 쪽이 맞는 값인지는 안쪽 요소가 알려 줍니다.

요소패널 안 x800 기준 가운데791 기준 가운데
Login Form (400)200200 ✓195.5
Copyright (298)251251 ✓246.5

둘 다 800 기준으로 정확히 가운데입니다. 폼을 놓은 뒤 패널만 791 로 좁혀진 것으로 보고 패널을 800 으로 되돌렸습니다. 그러면 1120 + 800 = 1920 으로 딱 맞고, 폼과 저작권 줄의 가로 위치는 Figma 값 그대로가 됩니다.

구현에서는 로그인 면만 800 고정이고 브랜드 면이 나머지를 먹습니다 — 1920 이 아닌 폭에서도 폼의 여백이 흔들리지 않습니다.

2. 브랜드 덩어리가 왼쪽 면 가운데가 아니었습니다

로그인 화면의 락업+태그라인 덩어리(283 × 231)가 x = 507 에 있었습니다. 1120 면의 가운데는 418.5 라 88.5 오른쪽으로 밀려 있었습니다. 세로도 y = 355 로 가운데(396.5)보다 41.5 위였습니다. 가로·세로 모두 가운데로 옮겼습니다.

3. 로고는 가운데인데 글자는 왼쪽이었습니다

로그인 화면의 Tagline 은 counterAxisAlignItems = MIN 이라 두 줄이 왼쪽에 붙습니다. 그런데 그 위 로고는 가운데라, 짧은 국문 줄(222)이 긴 영문 줄(283) 안에서 왼쪽으로 쏠려 보였습니다. 스플래시와 같이 가운데 정렬로 맞췄습니다(스플래시 쪽은 CENTER 입니다).

4. 폼이 위로 붙어 아래가 351 비어 있었습니다

Figma 는 Login Form 이 y = 222 에서 시작해 673 에서 끝나고, 저작권 줄이 944 에 따로 놓여 있습니다. 그 사이 351 이 그냥 빕니다.

구현은 저작권 줄을 뺀 나머지 자리의 한가운데에 폼을 세웁니다 (열 방향 flex 에 margin: auto 0). 위아래 여백 64 를 주면 저작권 줄이 y = 942 에 서는데 Figma 의 944 와 2 차이입니다 — 저작권 줄은 사실상 그대로고 폼만 56 내려온 셈입니다.

5. 체크박스 — 컴포넌트에서 둘을 고쳤습니다

Figma Checkbox여기
상자 자리라벨 오른쪽(자식 순서가 Label → Box)왼쪽
아래 테두리border/default 1px — Default 세 변형에만 있고 Disabled 두 변형에는 없습니다없음

아래 테두리는 변형끼리 어긋나 있어 남은 자국으로 봤습니다. 나머지(상자 18 · radius 4 · 패딩 8/8/8/12 · gap 8 · 줄 높이 38 · On 일 때 bg/brand 면 + 14 짜리 check)는 Figma 그대로입니다.

Figma 컴포넌트는 손대지 않았습니다. 다른 화면에서도 쓰는 컴포넌트라 말씀 주시면 그때 고치겠습니다.

6. 입력칸 안내 문구를 placeholder 로 내렸습니다

Figma 는 Text Field 의 Value 자리에 "사번 또는 아이디를 입력하세요" 를 fg/primary 로 적어 두었습니다. 실제로는 친 글자가 아니라 안내 문구라서 fg/tertiary 로 낮췄습니다. 친 글자가 fg/primary 입니다.

7. 눈 아이콘을 실제 토글로 만들었습니다

Figma 에는 Icon / eye-off 만 놓여 있고 상태가 없습니다. 누르면 Icon / eye 로 바뀌며 비밀번호가 보입니다 (aria-pressed 로 상태를 알립니다). 두 아이콘 모두 Figma 의 01.7 Icon 페이지에서 내려받아 assets/icons/ 에 넣었습니다.

8. 그대로 둔 것

  • 로그인 버튼이 Secondary 입니다 — 화면의 주 동작인데 보조 버튼입니다. 정렬 문제가 아니라 고르신 값이라 그린 대로 뒀습니다. Primary 로 바꿀지는 말씀해 주세요.
  • Options 줄의 오른쪽이 비어 있습니다. SPACE_BETWEEN 인데 자식이 체크박스 하나뿐입니다. "비밀번호 찾기" 같은 링크 자리로 보고 줄은 그대로 두었습니다.
  • 태그라인 아랫줄이 두 화면에서 다릅니다. 스플래시는 Label/1(14/20 ExtraBold) 대문자, 로그인은 Body/4(13/20 Regular) 원래 대소문자입니다. 크기 차이는 의도로 보고 뒀습니다.
  • 락업 흰색. Figma 가 변수 없이 #FFFFFF 로 박아 둔 값이라 여기서도 흰색 그대로입니다. Light 로 뒤집을 때만 fg/primary 로 넘어갑니다.

9. 타입 램프 이름을 Figma 에 다시 맞췄습니다

Body 램프에 Body/4 가 끼면서 번호가 한 칸씩 밀려 있었습니다. app-shell.css 의 .t-* 는 예전 이름이라 .t-body-2 가 14/22 를 가리키고 있었습니다.

클래스전후 (Figma 현재)
.t-body-1없음20/32 SemiBold
.t-body-214/2216/24
.t-body-313/2014/22
.t-body-4없음13/20
.t-heading-2없음24/32 SemiBold, -1%

쓰이던 곳은 세 화면의 사이트 셀렉트 하나뿐이라 t-body-3 → t-body-4 로 바꿨습니다 — 그려지는 크기는 그대로고 이름만 맞았습니다.

Typography/Label/1/SemiBold 는 실제 굵기가 ExtraBold(800) 입니다. 이름과 값이 어긋난 스타일이 넷(Heading/3 · Label/1 · Title/1,2 · Body/1)인데 여기서는 값을 따릅니다 — 전부터 그렇게 두고 있던 규칙입니다.

11. 화면 밖 동작

  • 스플래시 → 로그인 — 2 초 머문 뒤 넘어갑니다. 누르거나 키를 치면 바로 넘어가고, ?hold=0 으로 열면 멈춰 있습니다(캡처용).
  • 로그인 → 관제 화면 — 붙일 인증이 없어서 값을 확인하지 않고 dashboard-home.html 로 넘깁니다. 서버가 붙으면 그 자리가 요청으로 바뀝니다.
  • 1080 아래 — 브랜드 면을 접고 로그인 면만 남깁니다. 관제실 기준이 1920 이라 별도 화면을 그리는 대신 무너지지만 않게 했습니다.
