Map Panel 의 테두리는 넣지 않았습니다. Figma 에는 border/default 1px stroke 가 걸려 있는데, 지도 영역에 선이 보이면 안 된다고 하셔서 뺐습니다. Figma 쪽도 지우시는 게 맞을 것 같습니다.

Robot Card 의 Selected 색이 바뀌어 반영했습니다. 단색이 아니라 세로 그라데이션이고, stop 셋이 모두 토큰에 묶여 있어 두 모드를 알아서 따라갑니다. 줄 배경은 새 토큰 bg/surface/alpha(어두운 scrim 50%)입니다. Semantic 이 122 → 123이 되었습니다.

Light 에서 두 가지가 걸립니다. 확인 부탁드립니다.

  • Light 에서는 그라데이션이 사라집니다. 30% 와 98% stop 이 bg/surface/selected · status/info/bg인데 Light 에서 둘 다 main/100이라 같은 색입니다. 결과적으로 평평한 면에 아래 2%만 진한 파란 선으로 남습니다.
  • Light 에서 선택된 줄의 값이 읽히지 않습니다. scrim 이 두 모드 같은 어두운 색이라 Light 에서 줄 배경이 #7C828A가 되는데, 그 위에 올라가는 값은 Light 용 어두운 색입니다. status/info/fg 대비 1.11, status/normal/fg 1.52입니다(흰 라벨은 3.88). Dark 는 각각 7.43 · 5.47 로 넉넉합니다. bg/surface/alpha를 Light 에서 밝은 scrim 으로 두거나, 선택된 줄의 값 색을 Light 에서도 밝은 쪽으로 잡아야 할 것 같습니다. Figma 그대로 두었습니다.

맞추는 과정에서 저희 쪽 어긋남 넷도 같이 고쳤습니다. 로봇 카드의 Mission/Battery/Signal 행이 24가 아니라 26~34로 나오고 있었고(패딩 때문), AI 바가 닫힌 상태에서 68이 아니라 88이었으며(접힌 쪽이 gap을 먹고 있었습니다), 오른쪽 패널이 420이 아니라 425였고(로봇 카드 3장의 min-content가 바닥이 되어 있었습니다), 상태바가 64가 아니라 66이었습니다(Figma의 안쪽 stroke는 높이를 늘리지 않는데 CSS border는 늘립니다).

3. 디자인 시스템에서 바뀐 것

Component 컬렉션이 없어지고 button/* 32개가 Semantic으로 들어왔습니다. 컬렉션 구성이 Primitive(111) · Semantic(122) · Texts(7)이 되었습니다.

  • main 램프가 11단계로 재설계됐습니다 (50~950). 이전은 7단계였습니다.
  • 원색 3개가 바뀌었습니다 — danger/500 #F03918 → #FF383C, safe/300 #5FD382 → #34C759, warning/500 #EECE1B → #FFCC00
  • size/panel/right 360 → 420, space/2 추가
  • bg/container Dark가 gray/850 → gray/800, bg/brand Dark가 main/500 → main/600
  • Dark의 상태 아이콘 3개가 300 → 500으로 (원색을 그대로 쓰는 방향)
  • Texts 컬렉션(문자열 7개)이 새로 생겼습니다. 화면 문구용이라 CSS로는 내보내지 않았습니다.

4. 확인이 필요한 지점

  • button/* 32개의 Light와 Dark 값이 전부 같습니다. Component 컬렉션에 있을 때는 별칭 하나(bg/inverse 등)가 모드를 알아서 따라갔는데, Semantic으로 옮기면서 두 모드에 Light 값이 같이 들어갔습니다. 눈에 띄는 두 곳입니다 — button/primary/bg/default가 gray/950이라 bg/canvas와 같은 색이고, button/secondary/bg/default가 gray/0이라 어두운 화면 위에 흰 버튼이 놓입니다. 의도한 것인지 확인 부탁드립니다. Figma를 그대로 따랐습니다.
  • input/border/* · navigation/item/* · table/row/* 10개가 이관 없이 사라졌습니다. Text Field · Select · Nav Item · GNB Rail Item · Table Row의 바인딩 확인이 필요합니다. 여기서는 대응하는 Semantic(border/control 등)을 직접 씁니다.
  • Waypoint 텍스트 속성이 동작하지 않습니다. 7개 항목 모두 Waypoint = "Thrust Oil 정유기 운전 상태"로 설정돼 있는데, 텍스트 레이어가 Texts 컬렉션의 문자열 변수(Waypoint/Default · Waypoint/예시 1)에 묶여 있어 변수 바인딩이 컴포넌트 속성을 이깁니다. 그래서 화면에는 "waypoint name"이 나옵니다. 둘 중 하나를 끊어야 합니다.
  • Show Progress = true인데 진행 블록이 어디에도 안 나옵니다. 7개 항목 전부에 Progress Label = "센서 판독 진행", Progress Value = "3 / 5 지점 · 62%"가 들어가 있지만 화면에 없습니다. Show Description = true도 마찬가지로 Running 항목에서만 보입니다. Done · Pending Variant 에 해당 레이어가 없어서 불리언이 무력화된 것으로 보입니다.
  • 로봇 카드는 정리됐습니다. 이전 판에서 3장 모두 State = Running에 1번만 수동 fill 오버라이드였는데, 지금은 Running · Returning · Idle로 갈렸고 선택된 면도 Variant 가 갖습니다. 오버라이드는 크기뿐입니다. 다만 Running이 "수행 중"인 동시에 "선택됨"을 겸하고 있어서, 수행 중인 로봇이 둘이 되면 표현할 방법이 없습니다. 카드에 텍스트 속성이 둘인 것도 그대로입니다 — Robot = "ROBOT 02"(화면에 안 나옴), 로봇명 = "로봇명"(화면에 나옴).
  • Mode Badge 가 Status = Normal인데 중립색으로 오버라이드돼 있습니다. 오버라이드 3개가 걸려 있어 초록 대신 fg/secondary로 나옵니다.
  • Turbine Select 에 Label = "터빈 선택", Helper = "현재 관제 대상 터빈을 선택합니다."가 들어 있지만 Show Label · Show Helper가 false 라 숨겨져 있습니다. 화면도 그대로 두었습니다.
  • Status Bar 로고가 raw white입니다. 토큰이 아니라서 Light 모드에서는 흰 면 위 흰 로고가 됩니다. 여기서는 fg/primary로 두었습니다.
  • Robot Card의 Mission/Battery/Signal 라벨이 raw white입니다. 토큰이 아니라서 Light 모드에서는 흰 면 위 흰 글자가 됩니다. 여기서는 fg/secondary로 두었습니다.
  • Gradient/Main의 방향이 뒤집혔습니다. 코어가 오른쪽 끝이고 왼쪽으로 감쇠합니다. 나머지 셋은 여전히 코어가 왼쪽입니다. 또 최소 알파가 0이 아니라 0.1이라 완전히 사라지지 않습니다. (이 화면에서는 그라데이션을 쓰지 않아 눈에 띄지 않습니다.)
  • Text Style 이름과 실제 굵기가 어긋납니다. Heading/3/SemiBold와 Label/1/SemiBold는 실제 ExtraBold, Title/1/SemiBold는 실제 Bold입니다. 실제 굵기를 따랐습니다.
  • Mission Timeline Iist — List의 l이 대문자 I입니다. 지난번에도 남아 있던 오타입니다.
  • 진행률이 3 / 5 · 00%로 서로 맞지 않았습니다. 웨이포인트가 로봇 선택에 따라 달라지게 되면서 진행률은 단계에서 계산합니다 — 1번 로봇은 7단계 중 3단계 완료라 3 / 7 · 43%로 나옵니다. Figma 쪽 값도 맞춰 주시면 좋겠습니다.

5. AI(Delta) 요약 — closed / opened

AI Assist Panel의 Emphasis 속성(closed · opened)을 우측 상단 토글 버튼으로 전환합니다. 기본은 closed 입니다. 닫힘 ^ · 열림 v로 방향이 바뀌고, chevron-down 하나를 돌려 씁니다.

두 상태를 모두 DOM에 두고 grid-template-rows를 0fr ↔ 1fr로 여닫습니다. height: auto는 전환이 안 되지만 이 방식은 됩니다. prefers-reduced-motion이 켜진 환경에서는 전환 없이 바로 바뀝니다. 펼친 상태에서 Esc로 닫을 수 있고, 초점은 버튼에 남습니다.

닫힌 상태의 2px 상단 테두리(border/focus)는 열릴 때 투명해집니다 — Figma의 opened에는 테두리가 없지만, 폭을 0으로 만들면 여닫을 때 2px씩 튀어서 색만 없앴습니다.

6. 붙인 동작 — 패널 접기 · 로봇 선택

사이트 패널 접기. 우상단 panel-left 버튼으로 여닫습니다. 접힌 모습은 Figma에 없어서 여기서 정했습니다 — 버튼만 남는 44(12+20+12) 폭으로 줄이고 남는 자리는 지도가 가져갑니다. 버튼이 패널 안에 있어서 폭을 0으로 만들 수는 없었습니다. 접히면 아이콘이 좌우로 뒤집혀 "펼치기"로 읽힙니다. 접힌 상태를 그려 주시면 그대로 맞추겠습니다.

로봇 선택. 카드를 누르면 Robot Card의 Type = Default ↔ Selected가 바뀝니다. 두 Variant의 차이는 카드 면 (bg/surface/selected) 하나뿐이라 그대로 옮겼습니다. 한 번에 하나만 선택됩니다(aria-pressed).

선택에 따라 아래 waypoint 목록과 진행률이 바뀝니다. Figma에는 타임라인이 하나뿐이라 2·3번 로봇의 내용은 여기서 지었습니다 — 카드에 걸린 상태를 따랐습니다.

7. 그대로 둔 것 · 코드에서 정한 것

문구는 자리표시자 그대로 둡니다. 로봇명 ×3, waypoint name, 전체 미션명, 채워지지 않은 사각형 자리 모두 Figma 그대로입니다. 진행률(00%)만 계산 값으로 바뀌었습니다 — 아래 7번을 봐 주세요.

스크롤바도 토큰으로 맞췄습니다. Figma 에 없는 부분이라 코드에서 정했습니다 — 막대는 border/default, 손이 닿으면 border/strong으로 한 단 진해집니다. Light 는 gray/300 → 400(어두워짐), Dark 는 gray/650 → 600(밝아짐)이라 두 모드 모두 대비가 커지는 방향입니다. 트랙은 비워 두고 패널 면(bg/canvas)이 비칩니다. 막대는 radius/pill이고 실제 두께는 4px 입니다. Chrome · Safari 는 ::-webkit-scrollbar, Firefox 는 scrollbar-color로 갈라 뒀습니다 — 둘을 같이 주면 Chrome 이 표준 속성을 우선하면서 앞쪽을 무시합니다. 타임라인 · 로봇 카드 · 사이트 패널 · GNB 에 같이 적용했습니다.

무엇이 늘어나는지는 코드에서 정했습니다 — 고정 폭은 GNB(76) · Context Panel(240) · Right Panel(420) 셋뿐이고 지도가 나머지를 흡수합니다. 우측 패널은 높이를 채우고 타임라인만 스크롤합니다. 웨이포인트가 7개로 늘어난 지금은 이게 없으면 아래쪽이 잘립니다. 로봇 카드는 대수 상한이 미정이라 132px 아래로는 줄지 않고 그보다 좁아지면 가로로 스크롤합니다.
