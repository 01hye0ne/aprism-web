2. 디자인 시스템에서 바뀐 것

Component 컬렉션이 없어지고 button/* 32개가 Semantic으로 들어왔습니다. 컬렉션 구성이 Primitive(111) · Semantic(122) · Texts(7)이 되었습니다.

  • main 램프가 11단계로 재설계됐습니다 (50~950). 이전은 7단계였습니다.
  • 원색 3개가 바뀌었습니다 — danger/500 #F03918 → #FF383C, safe/300 #5FD382 → #34C759, warning/500 #EECE1B → #FFCC00
  • size/panel/right 360 → 420, space/2 추가
  • bg/container Dark가 gray/850 → gray/800, bg/brand Dark가 main/500 → main/600
  • Dark의 상태 아이콘 3개가 300 → 500으로 (원색을 그대로 쓰는 방향)
  • Texts 컬렉션(문자열 7개)이 새로 생겼습니다. 화면 문구용이라 CSS로는 내보내지 않았습니다.

3. 확인이 필요한 지점

  • button/* 32개의 Light와 Dark 값이 전부 같습니다. Component 컬렉션에 있을 때는 별칭 하나(bg/inverse 등)가 모드를 알아서 따라갔는데, Semantic으로 옮기면서 두 모드에 Light 값이 같이 들어갔습니다. 눈에 띄는 두 곳입니다 — button/primary/bg/default가 gray/950이라 bg/canvas와 같은 색이고, button/secondary/bg/default가 gray/0이라 어두운 화면 위에 흰 버튼이 놓입니다. 의도한 것인지 확인 부탁드립니다. Figma를 그대로 따랐습니다.
  • input/border/* · navigation/item/* · table/row/* 10개가 이관 없이 사라졌습니다. Text Field · Select · Nav Item · GNB Rail Item · Table Row의 바인딩 확인이 필요합니다. 여기서는 대응하는 Semantic(border/control 등)을 직접 씁니다.
  • Robot Card의 Mission/Battery/Signal 라벨이 raw white입니다. 토큰이 아니라서 Light 모드에서는 흰 면 위 흰 글자가 됩니다. 여기서는 fg/secondary로 두었습니다.
  • Gradient/Main의 방향이 뒤집혔습니다. 코어가 오른쪽 끝이고 왼쪽으로 감쇠합니다. 나머지 셋은 여전히 코어가 왼쪽입니다. 또 최소 알파가 0이 아니라 0.1이라 완전히 사라지지 않습니다. (이 화면에서는 그라데이션을 쓰지 않아 눈에 띄지 않습니다.)
  • Text Style 이름과 실제 굵기가 어긋납니다. Heading/3/SemiBold와 Label/1/SemiBold는 실제 ExtraBold, Title/1/SemiBold는 실제 Bold입니다. 실제 굵기를 따랐습니다.
  • Mission Timeline Iist — List의 l이 대문자 I입니다. 지난번에도 남아 있던 오타입니다.
  • 진행률이 여전히 3 / 5 · 00%입니다. 3/5는 60%입니다.

4. 그대로 둔 것 · 코드에서 정한 것

문구는 한 글자도 바꾸지 않았습니다. 로봇명 ×3, waypoint name ×7, 전체 미션명, 00%, 채워지지 않은 사각형 자리 모두 Figma 그대로입니다.

무엇이 늘어나는지는 코드에서 정했습니다 — 고정 폭은 GNB(76) · Context Panel(240) · Right Panel(420) 셋뿐이고 지도가 나머지를 흡수합니다. 우측 패널은 높이를 채우고 타임라인만 스크롤합니다. 웨이포인트가 7개로 늘어난 지금은 이게 없으면 아래쪽이 잘립니다. 로봇 카드는 대수 상한이 미정이라 132px 아래로는 줄지 않고 그보다 좁아지면 가로로 스크롤합니다.
