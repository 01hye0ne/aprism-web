# source — 넣어두는 곳

디자이너가 Figma 에서 내보낸 파일을 **그냥 여기 두면** 됩니다.
이름도 폴더도 신경 쓰지 않아도 됩니다.

## 어떻게 되나

파일을 실제로 화면에 쓸 때 Claude 가 **여기서 꺼내 제자리로 옮깁니다.**

| 파일 | 옮겨가는 곳 |
|---|---|
| `icon-*.svg` | `assets/icons/` — 옮긴 뒤 `tools/inline-icons.py` 로 CSS 에 인라인됩니다(`--ic-이름`) |
| 화면에 쓰는 그림 | `assets/img/` |
| Figma 자리표시자 | `assets/figma/` |

옮기고 나면 여기서는 없어집니다. **여기 남아 있는 파일 = 아직 안 쓰는 파일** 입니다.

## 한 가지만

Claude 가 이 폴더를 계속 지켜보지는 않습니다.
**넣으셨으면 한 마디만 해 주세요** — "소스에 로봇개 넣어놨어" 정도면 충분합니다.
