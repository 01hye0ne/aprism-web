Strands 검토

React Bits 의 Strands 애니메이션입니다. 무료·공개라 레지스트리에서 실제 소스를 받아왔고, 아래 무대는 그 소스의 셰이더를 한 글자도 바꾸지 않고 돌린 것입니다.

됩니다 — 셰이더가 전부라 React 없이도 그대로 돌아갑니다

reactbits.dev/r/Strands-JS-CSS.json 에서 받은 소스를 뜯어보니 내용물은 WebGL2 프래그먼트 셰이더 두 개이고, React 부분은 캔버스를 만들고 uniform 을 넘기는 껍데기 120 줄입니다. 의존성 ogl@^1.0.11 도 그 껍데기에만 쓰입니다.

그래서 셰이더는 원본 그대로 두고 껍데기만 순수 WebGL2 로 옮겼습니다. React 도 번들러도 ogl 도 필요 없고, 지금의 정적 HTML 구조를 건드리지 않습니다. 화면에 나오는 그림은 원본과 같은 계산 결과입니다.

라이선스는 확인이 필요합니다

React Bits 는 MIT + Commons Clause 입니다. 웹사이트·제품에 쓰는 것은 상업적 이용까지 허용되지만, 컴포넌트 자체를 팔거나 재배포하는 것은 금지이고 조항에 “이식한 것(ported version)”까지 명시돼 있습니다.

aprism-web 은 공개 저장소입니다. 화면에 쓰는 것은 문제가 없지만, 옮긴 소스가 공개 저장소에 그대로 올라가 있는 상태를 저작자가 “이식본 재배포”로 볼 여지가 있습니다. 저작권 표시는 파일 안에 넣어두었습니다. 검토 뒤 판단해 주세요 — 걸리면 저장소를 비공개로 돌리거나 이 페이지만 빼는 선택지가 있습니다.

주신 설정 그대로

colors 3개 · count 3 · speed 0.5 … 문서에 적어주신 값이 기본값입니다. 바탕을 바꿔가며 우리 화면에 얹었을 때를 봅니다 — 캔버스는 투명이라 뒤가 그대로 비칩니다.
