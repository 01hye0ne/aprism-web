화면 퍼블리싱 인덱스

Figma 와이어프레임을 웹으로 퍼블리싱하고 공유하기 위한 페이지입니다. 작업된 화면은 아래 목록에 추가됩니다.

진입점

화면

  • CM-01 스플래시 진입 화면. 로고와 태그라인이 잠깐 머문 뒤 로그인으로 넘어갑니다 — 누르면 바로 넘어가고, ?hold=0 으로 열면 멈춰 있습니다.
  • CM-02 로그인 좌측 브랜드 면 + 우측 로그인 면. 아이디 · 비밀번호 · 자동 로그인. 퍼블리싱 노트
  • Screen 04.1 통합 관제 메인 · 미션 설정 같은 셸, 우측 패널이 미션 생성 폼(이름 · 대상 · 로봇 · 점검 항목 · 스케줄러) 상태입니다.
  • Screen 04.1 통합 관제 메인 · 사전 점검 같은 셸, 우측 패널이 미션 시작 전 자동 점검(Manager · Spot · Battery · Mission) 진행 상태입니다.
  • Screen 04.1 통합 관제 메인 · 미션 모니터링 GNB · 사이트 컨텍스트 · 지도 · 로봇/미션 패널. 우측 패널은 미션 진행 모니터링 상태입니다. 퍼블리싱 노트
  • 준비 중 다음 화면 Figma 프레임 링크를 받으면 추가합니다.

피그마 문서

  • Change Set Figma 반영 목록 확정된 값을 디자인 시스템에 옮기기 위한 변경 목록과 변경 로그.
  • Foundations 톤 실험실 색온도와 층위 간격을 조정하며 실제 화면과 대비 기준으로 검증하는 도구.
  • Foundations 데이터 서체 검토 수치·코드 표기에 모노스페이스가 필요한지 판단하는 비교 페이지.
  • Foundations Strands 검토 React Bits 의 Strands 애니메이션을 원본 셰이더 그대로 돌려보는 페이지.
  • Foundations Primitive 톤 감사 현재 램프의 명도, 색온도, 대비 검증과 확인이 필요한 지점.
